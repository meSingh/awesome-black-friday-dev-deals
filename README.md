## How a deal gets listed

Each deal is one small file in [`deals/`](deals). You add yours as a pull request, or fill in the form and the file is written for you. A quick automatic review looks at the link, the dates and the discount, then replies: listed, or what to fix. The rules are in the open in [`scripts/lib.mjs`](scripts/lib.mjs) if you want to read them.

Deals change, so look at the seller's page before you buy. Spotted one that has expired or is wrong? [Tell me here](https://github.com/meSingh/awesome-black-friday-dev-deals/issues/new?template=report-deal.yml).
